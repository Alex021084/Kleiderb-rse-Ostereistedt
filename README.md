# Kleiderbörse Kasse V3

## Funktionen
- Startseite mit Verkäuferverwaltung
- Verkäufernummer + Name
- Verkäuferdetail mit verkauften Teilen, Umsatz, 15 % Provision und Auszahlung
- Einzelne Verkäuferabrechnung drucken bzw. als PDF speichern
- Kasse mit übersichtlichem Kassenzettel
- Kleidung oder Spielzeug
- Verkäufernummer, Größe und Preis
- Zahlung: Bar, EC/Karte, PayPal
- Tagesübersicht nach Zahlungsart
- Tagesabschluss drucken bzw. als PDF speichern
- Verkaufshistorie
- Speicherung im Browser via localStorage

## GitHub Pages
Die drei Dateien `index.html`, `style.css` und `app.js` in das Repository laden. GitHub Pages auf `main` / `/ (root)` stellen.

## Hinweis
Dies ist weiterhin ein Prototyp. Die Zahlungen werden nicht technisch über EC/PayPal abgewickelt, sondern nur als Zahlungsart für die Kassenprüfung gespeichert. Die Daten sind derzeit browserlokal. Für einen echten Börsenbetrieb sollte anschließend eine gemeinsame Datenbank mit Backup und ggf. mehreren Kassen ergänzt werden.
